# Demo Script

1. Start with `./start.sh`.
2. Open `/operations` and run `Refresh live`.
3. Open `/map` to show vessel positions and geo overlays.
4. Select a vessel with a risk color; note that non-focused vessels fade and risk vessels sort above ordinary vessels.
5. Search `/vessels` and open a vessel detail page.
6. Refresh particulars/movements and inspect evidence.
7. Open `/ports` and pull arrivals/departures for the current date.
8. Open `/risk` or `/sanctions` to show the server-loaded risk feed.
9. Search `/entities` and open a company owner/operator/manager page.
10. Open `/graph` for a vessel or entity ID and inspect evidence-linked edges.
11. Open `/schema` to explain the architecture.
12. Close with guardrails: manual-first, evidence-driven, no AI, no numeric score.
