# Demo Script

1. Start with `./start.sh`.
2. Open `/dev` and run `Refresh live`.
3. Open `/map` to show vessel positions and geo overlays.
4. Search `/vessels` and open a vessel detail page.
5. Refresh particulars/movements and inspect evidence.
6. Search `/entities` and open an owner/operator page.
7. Open `/graph` for a vessel or entity ID and inspect evidence-linked edges.
8. Open `/schema` to explain the architecture.
9. Close with guardrails: manual-first, evidence-driven, no AI, no numeric score.
